# Kaikou Sushi — Site demonstrativo

Projeto estático em HTML, CSS e JavaScript, responsivo e sem dependências de instalação.

## Como executar no GitHub Codespaces
1. Envie os arquivos `index.html`, `style.css` e `script.js` para o repositório.
2. Abra `index.html` com a extensão **Live Server** ou execute no terminal:

```bash
python3 -m http.server 8000
```

3. Abra a aba **Ports**, encaminhe a porta `8000` e clique em **Open in Browser**.

## Antes de publicar
- Substitua o número fictício em `script.js` pelo WhatsApp oficial.
- Confirme endereço, horários, cardápio, preços e canais de pedido com o restaurante.
- As fotos são carregadas do Unsplash e precisam de internet.
- Os produtos e valores são ilustrativos. Os botões apenas demonstram a interação e não enviam pedidos.
